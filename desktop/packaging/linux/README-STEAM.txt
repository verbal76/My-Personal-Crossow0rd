My Personal Crossword (desktop) - Linux x86-64 build
====================================================
Run:        ./steam-launch.sh            (windowed)
            ./steam-launch.sh --fullscreen
Runtime:    Java 21 is BUNDLED (jpackage). Needs only glibc and X11/Wayland (XWayland on Deck) with the
            usual libs: libX11, libXext, libXrender, libXtst, libXi, libfreetype, libfontconfig.
Saves:      $XDG_DATA_HOME/HotAtticGames/MyPersonalCrossword  (default ~/.local/share/...)
Controls:   Keyboard: letters, arrows, Tab/Shift+Tab next/prev clue, Space flip, Backspace, F1 hint,
                      Esc menu, F11 or Alt+Enter fullscreen.
            Mouse/touch: click squares, clues, on-screen keys, header buttons.
            Controller (Xbox layout / Steam Input): D-pad or sticks move, A select / open on-screen
                      keyboard, B back/close, X flip, Y hint, LB/RB prev/next clue, Start menu, Back = keyboard.
Not verified on real Steam Deck hardware yet; see docs/DESKTOP.md.
